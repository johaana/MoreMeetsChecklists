# **App Name**: MoreMeets: Smart Checklists

## Core Features:

- User Authentication: Enable user signup/login via Email and Google OAuth using Firebase Auth.
- Checklist Templates: Provide pre-built checklist templates for events, hospitality, training, and sustainability.
- Custom Checklist Creation: Allow users to create and edit custom checklists with due dates, assignees, and priority levels.
- AI Task Suggestion: AI tool to suggest missing tasks based on the selected checklist type (e.g., suggesting a generator for an outdoor wedding).
- Photo Uploads: Allow staff to upload photo evidence for task completion (relevant to hospitality and sustainability checklists).
- Checklist Sharing: Enable checklist sharing with team members/guests via a shareable link.
- Dashboard Overview: Show upcoming events/tasks and completion percentages on a user dashboard.

## Style Guidelines:

- Primary color: Sky blue (#38bdf8) evokes the festive spirit of events while maintaining a professional feel. This is the primary hue.
- Background color: Light gray (#f0f0f5) provides a neutral backdrop that won't compete with the content.
- Accent color: Gold (#FFD700) highlights key elements, inspired by the original requests for event theming, to convey elegance and importance. (Consider: slightly desaturated or darkened variations for improved readability depending on implementation)
- Body and headline font: 'PT Sans' for a modern yet warm feel suitable for both headlines and body text. It is also very readable on mobile devices, matching the mobile-first style described in the original request.
- Employ clear and intuitive icons to visually represent each checklist type (events, hospitality, training, sustainability) for easy navigation. Icon styles to match font, clean and modern.
- Design a clean, mobile-first layout with a tab-based navigation system to allow users to easily switch between the events, hospitality, training, and sustainability categories, matching the navigation guidance in the original request.
- Incorporate subtle animations and transitions to provide feedback and enhance user experience, for instance, loading states.
